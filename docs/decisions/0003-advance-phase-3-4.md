# ADR-0003: 学生期間中に Phase 3/4 へ前倒し着手し、市場検証は skip 継続する

> Status: accepted
> Date: 2026-04-28
> Deciders: operator, agent
> Supersedes: ADR-0002 §「長期」の「市場検証は社会人以降」「Phase 4 前に必ず市場検証を通す」

## 文脈 (Context)

ADR-0002 (2026-04-26) では「学生期間中は技術検証を優先し、市場検証は社会人化以降に
実施する」方針で Phase 0 を skip し、Phase 4 ローンチ前に市場検証を必ず通す前提で
あった。

Phase 1 (ローカル PoC) は予定通り 2026-04-26 中に完了し、Phase 2 (GitHub App 化)
も 2026-04-28 に E2E `pr_ready` 達成で完了基準を満たした。当初想定 (Phase 1 で
2〜4 週間 + Phase 2 で 2〜3 週間 = 計 4〜7 週間) に対し実工数 **約 3 日** で済んだ。

operator はこれを踏まえ「Phase 2 が想定より早く終わったので前倒し」を理由として、
Phase 3 (課金統合) と Phase 4 (ローンチ準備) に学生期間中に着手することを判断した。
合わせて市場検証 (Phase 0 / ADR-0002 が要件としていた Phase 4 直前検証) は
**skip 継続** (ADR-0002 §1.4 の任意 PoC 公開等含む明示的市場検証手段は適用しない)
として進める判断を下した。

## 検討した選択肢 (Options)

### Option A: ADR-0002 通り Phase 3/4 を社会人化以降に延期

- 長所: 学生本業との両立、市場検証を実施する精神的余裕
- 短所: Phase 2 で動くものができた勢いを失う、社会人化後はまとまった時間が取れない
  恐れ

### Option B: Phase 3/4 に前倒し + Phase 4 直前で市場検証 (軽量版)

- 長所: ADR-0002 の「Phase 4 前必ず市場検証」を維持、ローンチ前の最終リスクチェック
- 短所: 検証で「需要薄」と判明した場合の心理的・工数的サンクコスト、operator は
  ヒアリング運用の負荷を許容しない方針

### Option C: Phase 3/4 に前倒し + 市場検証 skip 継続 (採用)

- 長所:
  - 最短でローンチまで到達できる
  - ローンチ後の売上・問合せが「事実」としての市場シグナルになる (仮説検証より直接)
  - operator がヒアリング運用を行わなくて済む
- 短所:
  - 仮説検証なしのローンチ → 売れなかった場合の Anthropic API + 月額固定費 +
    Phase 3/4 工数 (推定 2〜4 週間) のサンクコストが大きい
  - 返金保証 (`docs/business.md` §4.4) があるため、品質不足時の返金多発リスク
  - 憲章 §4.3「仮説と事実を区別する」との緊張は ADR-0002 を継承
  - ADR-0002 §「長期」で記した「Phase 4 前必ず市場検証」を破棄する判断
- リスク緩和:
  - Phase 4 §2.1「golden corpus 全件で CI green 達成」の品質ゲートを厳守し、
    返金トリガーを抑える
  - Phase 4 §2.4「最初の 3 件は割引価格でフィードバック収集」を**ベータローンチ
    として実施**し、ローンチ直後 3 件の実 repo 結果を「事後の市場検証」として扱う
  - 月額粗利 ¥10 万円目標 (`CLAUDE.md` §3) に対し、ローンチ後 1 ヶ月で 0 件なら
    「市場仮説の不成立」を ADR-0004 として正式記録し、横展開検討に移る
  - kill criteria は §1 に明文化

## 決定 (Decision)

**学生期間中に Phase 3 (課金統合) → Phase 4 (ローンチ準備) → ローンチまで進める。
市場検証 (顧客ヒアリング・煙テスト等) は実施しない。**

採用理由 (operator 直接の言葉):

> Phase 2 が想定より早く終わったので前倒し
> 市場検証は skip 継続 (案 C)

## 結果 (Consequences)

### 短期 (Phase 3 期間中)

- `docs/roadmap.md` §1.4 (Phase 3) 着手
- 新規外部サービス契約: Stripe (取引手数料のみ、月額固定費なし)、Resend (free tier)
- `docs/business.md` §4 の課金形態 ($99/$249/$499) と返金ポリシーをそのまま実装
- `apps/api` に Stripe checkout session 生成 + webhook handler を追加
- `packages/db` に payments / orders 相当のテーブルを追加

### 中期 (Phase 4 期間中)

- Landing page (価格表 / FAQ / プライバシーポリシー / 利用規約) — Phase 4 §2.4
- ドメイン取得 (固定費発生のため CLAUDE.md §6 で要再確認)
- Sentry (free Developer plan で start、必要なら $26/mo に)
- `docs/operations.md` の監視・キー管理・インシデントランブックの最低限整備

### ローンチ後

- 最初の 3 件は割引 (商品設計から決定) で実施し、本 ADR の「事後市場検証」と扱う
- ローンチ後 30 日で売上 0 件なら本 ADR §1 の kill criteria を発動し、ADR-0004 で
  ピボット (横展開先候補は `docs/business.md` §5) を検討
- 本 ADR は ADR-0002 §「長期」の「Phase 4 前必ず市場検証」要件を破棄したことを
  正式に記録

### 後続の判断への影響

- `CLAUDE.md` §6「公開文言: Landing page、利用規約、プライバシーポリシー、ローンチ
  投稿」は引き続き operator 確認必須
- 月額固定費を発生させる新規サービス (Sentry 有料プラン、ドメイン等) は §6 で都度確認
- 価格 ($99/$249/$499) の変更は §6 で都度確認

## §1. Kill Criteria (本 ADR の見直しトリガー)

ADR-0002 §1 の Phase 1 用 kill criteria は完了済 (Phase 1 / 2 終了)。本 ADR では
Phase 3 / 4 / ローンチ後の停止条件を別途定義する。

### §1.1 コスト超過

- Phase 3/4 完了までに **累計 Anthropic API + 月額固定費 + Stripe テスト手数料が
  累計 $200 USD** 到達時点で進捗評価。**$500 USD** で強制停止
- ローンチ後は `docs/operations.md` §2 のジョブ単位コスト上限を厳守

### §1.2 期間超過

- Phase 3 着手から **3 週間経過**で進捗評価。**6 週間経過**で強制停止
- Phase 4 着手から **3 週間経過**で進捗評価。**6 週間経過**で強制停止

### §1.3 ローンチ後の市場シグナル不在

- ローンチ後 30 日で売上 **0 件**なら ADR-0004 でピボット検討
- ローンチ後 90 日で月次粗利 **¥1 万円未満**なら横展開 (`docs/business.md` §5) へ
  方向転換を検討
- いずれの場合も「本 ADR の skip 判断が誤りだった」可能性を真摯に評価する

### §1.4 評価結果の記録

各しきい値到達時の評価結果は、本 ADR 末尾「実施結果」節に追記する。
